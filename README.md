# Quiz App

## Архітектура та структура папок (`src/`)

- `assets/` — статичні ресурси (стилі, зображення, шрифти).
- `components/` — глобальні та перевикористовувані UI-компоненти (кнопки, інпути, модальні вікна).
- `features/` — ізольовані функціональні модулі додатку (наприклад, вікторини, авторизація).
- `pages/` — високорівневі компоненти сторінок та конфігурація маршрутизації.
- `services/` — шар для роботи з мережевими запитами (API, Axios/Fetch).
- `store/` — централізоване управління станом додатку.
